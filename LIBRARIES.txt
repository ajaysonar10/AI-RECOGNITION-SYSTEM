1. OVERVIEW
----------------------------------------------------------------
BAS-AI is a real-time Human Activity Recognition System built for
on-board space experiment monitoring (Smart India Hackathon 2026).

It uses YOLO11 deep-learning models for human pose estimation and
object detection, OpenCV for camera/video processing, and a
Streamlit web dashboard for the user interface. Text-to-speech
voice alerts are generated with pyttsx3.

Requirements file: requirements.txt
---------------------------------
streamlit
opencv-python
ultralytics
numpy
pyttsx3

----------------------------------------
Installed version : 1.63.0
Role in project   : Web application framework - the entire user
                    interface runs on Streamlit.

Features used in this project:

3. PYTHON STANDARD LIBRARY MODULES USED
----------------------------------------------------------------

3.1 math
    Files : activity_detection.py, pose_detection.py,
            object_tracking.py, object_tasks.py, task_detection.py
    Use   : Knee-angle calculation (acos/degrees), hip movement
            distance (sqrt), geometry thresholds.

3.2 collections.deque
    Files : activity_detection.py, pose_detection.py,
            object_tracking.py, task_detection.py
    Use   : Fixed-size rolling buffers for motion history
            (walking detection) and track smoothing.

3.3 re (regular expressions)
    Files : task_detection.py, task_eval.py
    Use   : Parsing natural-language task text with word-boundary
            matching ("sit" must not match "visit").

3.4 datetime
    Files : app.py, camera.py, task_detection.py
    Use   : Date/time stamps for the activity history table and
            logs.

3.5 time
    Files : camera.py, task_eval.py, live_retest.py,
            live_task_suite.py
    Use   : Frame pacing, 1-sample-per-second logging, 10-second
            wrong-activity timer, elapsed session stats.

3.6 threading
    Files : camera.py
    Use   : Runs pyttsx3 voice alerts in a separate thread so the
            camera loop keeps running smoothly while speaking.

3.7 os / sys
    Files : test_walking_fix.py, test_object_tasks.py,
            test_task_verification.py, live_retest.py,
            live_task_suite.py
    Use   : Project-path setup so scripts run from any directory.

3.8 random
    Files : test_walking_fix.py
    Use   : Simulated jitter/drift movement to regression-test the
            walking detector without a camera.

4. AI MODEL FILES
----------------------------------------------------------------

4.1 yolo11n-pose.pt  (in repository, ~6 MB)
    - YOLO11 nano pose-estimation model
    - Detects 17 COCO human keypoints: nose, eyes, ears,
      shoulders, elbows, wrists, hips, knees, ankles
    - Used for: Standing / Sitting / Walking classification

4.2 yolo11n.pt  (auto-downloaded by ultralytics on first run)
    - YOLO11 nano object-detection model
    - Detects 80 COCO classes (bottle, chair, laptop, phone,
      book, table, etc.)
    - Used for: object tasks (pick up bottle, bottle on table,
      move bottle places...) and person-object proximity checks

6. INSTALLATION
----------------------------------------------------------------

  # 1. Clone
  git clone https://github.com/ajaysonar10/AI-RECOGNITION-SYSTEM.git
  cd AI-RECOGNITION-SYSTEM

  # 2. Install dependencies
  pip install -r requirements.txt

  # 3. Run
  streamlit run app.py

  First run downloads yolo11n.pt automatically.
  yolo11n-pose.pt is already included in the repository.

7. APPLICATION FEATURES SUMMARY
----------------------------------------------------------------
  - Real-time human pose detection (skeleton overlay on video)
  - Activity recognition: Walking / Standing / Sitting
  - Laptop webcam OR mobile camera (IP webcam over Wi-Fi)
  - Live task evaluation: type a task in plain English, AI
    verifies it frame-by-frame and gives a completion report
  - Object tasks: pick up bottle, bottle on table, move bottle
    between places, take object out of box, etc.
  - 10-second wrong-activity detection with offline voice alert
  - Activity history table + analytics dashboard (distribution
    chart, average confidence, anomaly count)
  - Step-by-step task progress bar and validation checklist
